Our Story

CampusConnect was built as a final project for Web Tech I to demonstrate a complete, deployable web application. The goal was to apply structured navigation, modular code, and modern CSS layout techniques (Flexbox and Grid) in a single cohesive site rather than a handful of disconnected pages.


Every page shares the same external stylesheet and script file, keeping the content, styling, and behaviour of the site clearly separated and easy to maintain.
